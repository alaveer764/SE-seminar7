Kuidas kasutada githubi ja vscodet ja muid asju

See leht tutvustab, kuidas kasutada ja commitida faile kasutades git bashi. Peamiselt taandub see kahe käsu kasutamisele, kuid võib kasutada ka kolmandat, millega saad infot failide ja commitide kohta. Need kaks käsku on git add ja git commit - esimene nendest lisab failid ettevalmistusalasse ja teine salvestab projekti hetkeseisu.


Vscode on üks väga kasulik tööriist koodi kirjutamisel. Kasutan seda iga päev!
